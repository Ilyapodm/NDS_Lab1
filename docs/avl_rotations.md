# Вращения AVLTree

`link` — ссылка на владеющий `unique_ptr` из вызывающего кода. Это может быть `root_` или поле `left` / `right` родителя. `new_root` — локальный `unique_ptr`, который временно владеет будущим корнем. Буквы A, B и C обозначают поддеревья, каждое из которых может быть пустым.

## Левое вращение

```text
До вращения                   После вращения

link --> X                    link --> Y
        / \                           / \
       A   Y                         X   C
          / \                       / \
         B   C                     A   B
```

1. `auto new_root = std::move(link->right)` передаёт Y вместе с B и C во владение `new_root`. Поле `X.right` становится пустым.
2. `link->right = std::move(new_root->left)` переносит B под X. B уже находится между X и Y в порядке компаратора, поэтому подходит на место правого поддерева X. Теперь можно обновить высоту X.

```text
После шага 1                  После шага 2

link --> X                    link --> X
        /                             / \
       A                             A   B

new_root --> Y                new_root --> Y
            / \                             \
           B   C                             C
```

3. `new_root->left = std::move(link)` подвешивает X под Y и временно оставляет `link` пустым. Теперь можно обновить высоту Y, поскольку высота X уже актуальна.
4. `link = std::move(new_root)` записывает Y в исходную владеющую ссылку. У родителя поддерева, либо у всего дерева, появляется новый корень.

## Правое вращение

```text
До вращения                   После вращения

link --> Y                    link --> X
        / \                           / \
       X   C                         A   Y
      / \                               / \
     A   B                             B   C
```

1. `auto new_root = std::move(link->left)` отделяет X. Поле `Y.left` становится пустым.
2. `link->left = std::move(new_root->right)` переносит B под Y. B предшествует Y в порядке компаратора. После переноса обновляем высоту Y.
3. `new_root->right = std::move(link)` подвешивает Y под X. Высота X теперь вычисляется по A и обновлённой высоте Y.
4. `link = std::move(new_root)` возвращает владение поддеревом вызывающему коду.

## Выбор вращения

`rebalance` вычисляет разность высот левого и правого поддеревьев. При двойном вращении сначала поворачивается тяжёлый ребёнок, затем корень поддерева.

| Случай | Баланс корня | Баланс тяжёлого ребёнка | Действие |
| --- | --- | --- | --- |
| LL | больше 1 | неотрицательный | вправо вокруг корня |
| LR | больше 1 | отрицательный | влево вокруг левого ребёнка, затем вправо вокруг корня |
| RR | меньше −1 | неположительный | влево вокруг корня |
| RL | меньше −1 | положительный | вправо вокруг правого ребёнка, затем влево вокруг корня |

Каждое вращение меняет только несколько связей и две высоты, поэтому занимает O(1). Узлы сохраняют свои адреса.
