# Консольный интерфейс AVLTree и Set

## Сборка и запуск

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build --target lab_ui
./build/src/lab_ui
```

Главное меню выбирает дерево, множества или автоматический пример. Интерфейс работает с int. Дерево и множества существуют всё время работы программы, поэтому переключение между режимами сохраняет данные.

Ввод выполняется построчно. Числовые команды должны занимать строку целиком. Программа повторяет запрос после неверного числа и возвращается в меню после ошибки операции. Конец входа завершает программу из любого вложенного меню.

## Общие действия

Действия 1–15 применяются к дереву или выбранному множеству.

| Команда | Действие |
| --- | --- |
| 1 | вывести значения в порядке компаратора |
| 2 | вставить одно значение, сообщить о дубликате |
| 3 | найти значение по ключу |
| 4 | удалить ключ |
| 5 | показать размер и признак пустоты |
| 6 | очистить контейнер |
| 7 | заменить содержимое списком целых чисел из одной строки |
| 8 | заменить содержимое автоматически созданными значениями |
| 9 | map с прибавлением или умножением на введённое число |
| 10 | where с условием больше границы, меньше границы или чётности |
| 11 | reduce с суммированием в long long |
| 12 | вывести сериализованную строку |
| 13 | восстановить контейнер из введённой строки |
| 14 | сохранить сериализацию в файл |
| 15 | загрузить сериализацию из файла |
| 0 | вернуться в главное меню |

Ручное заполнение объединяет дубликаты, пустая строка создаёт пустой контейнер. Автозаполнение создаёт уникальные значения от 0 до количества − 1. Порядок вставки выбирается между случайным, возрастающим и убывающим. Для случайного порядка используется фиксированный seed 2026. Количество ограничено представимостью int и доступной памятью.

map и where заменяют текущий контейнер результатом. Перед присваиванием новое дерево строится полностью. Для map промежуточное вычисление выполняется в long long, а результат проверяется на представимость int. Например, умножение на ноль объединяет все исходные ключи в один.

Ошибочный список, неудачное преобразование и некорректная сериализация сохраняют прежнее содержимое. Сохранение в файл перезаписывает выбранный файл. Путь читается целой строкой и может содержать пробелы.

## Режим дерева

Дополнительные команды доступны только для AVLTree.

- 20 выбирает один из шести DFS-порядков и выводит значения
- 21 выполняет BFS слева направо по уровням
- 22 сворачивает значения в строку в выбранном DFS-порядке
- 23 извлекает поддерево по значению корня и показывает его значения, размер и сериализацию

Строковая свёртка позволяет увидеть влияние порядка на результат некоммутативной операции. Суммирование из общего меню использует стандартный inorder.

Извлечение создаёт независимую копию и сохраняет исходное дерево. При отсутствии ключа выводится ошибка, после чего работа меню продолжается. Сериализованную строку результата можно использовать для восстановления через команду 13.

## Режим множеств

Хранятся A, B и R. При входе в режим активным становится A. Общие действия применяются к активному множеству. Через команду 20 можно выбрать A, B или R.

| Команда | Действие |
| --- | --- |
| 21 | записать объединение A и B в R |
| 22 | записать пересечение A и B в R |
| 23 | записать разность A и B в R |
| 24 | проверить включение в обе стороны |
| 25 | проверить равенство A и B |
| 26 | вывести A, B и R |
| 27 | обменять A и B |

Бинарные операции используют A как левый операнд, B как правый. Результат сохраняется отдельно в R, после чего его можно выбрать активным для дальнейшей обработки или сохранения. Обмен A и B позволяет вычислить разность в обратном направлении.

## Разделение файлов

- console_ui.cpp владеет контейнерами, главным меню и автоматическим примером
- tree_ui.cpp и set_ui.cpp содержат меню конкретных контейнеров
- ui_input.hpp читает и проверяет строки ввода
- ui_actions.hpp содержит общие действия двух контейнеров
- tree/tree_streams.hpp и set/set_streams.hpp определяют отдельные операторы <<

Вывод дерева имеет вид [1, 2, 3], множества — {1, 2, 3}. Операторы используют std::ostream и подходят для консольного, файлового и строкового вывода. Для восстановления используется serialize с маркерами формы дерева. Подробности формата приведены в [описании сериализации](avl_serialization.md).
