# AVLTree — согласованная архитектура базовых операций

## 1. Общие решения

- C++20, шаблонный класс `AVLTree<T, Compare = std::less<T>>`.
- Узлы владеют дочерними узлами через `std::unique_ptr<Node>`.
- Сырые указатели не используем (ограничение преподавателя).
- Для чтения существующего узла — `const Node&`.
- Для изменения структуры и владения — `std::unique_ptr<Node>&`.
- Для итеративных обходов — `std::reference_wrapper<const Node>`.
- Дубликаты запрещены. Эквивалентность определяется через `Compare`, а не `operator==`.
- AVL-инвариант поддерживается после каждой вставки и удаления.
- `Set<T, Compare>` позже строится поверх `AVLTree` через композицию.

## 2. Структура

```cpp
template <typename T, typename Compare = std::less<T>>
class AVLTree {
private:
    std::unique_ptr<Node> root_;
    std::size_t size_ = 0;
    Compare comp_;
};
```

Высота пустого поддерева — 0, листа — 1.

## 3. Базовые операции

### `find_result find(const T& key) const`

Возвращает:

```cpp
using find_result =
    std::optional<std::reference_wrapper<const T>>;
```

- Итеративный или рекурсивный поиск через компаратор.
- Если `comp_(key, value)` — переход влево.
- Если `comp_(value, key)` — переход вправо.
- Иначе элемент найден.
- Если элемента нет — `std::nullopt`.
- Значение не копируется, возвращается невладеющая константная ссылка через `std::cref`.
- Публичный API не раскрывает узлы дерева.

### `bool insert(const T& value)`

- Приватный рекурсивный `insert_impl(std::unique_ptr<Node>&, const T&)`.
- Поиск места и вставка выполняются за один проход.
- Если узел уже существует — `false`, дерево не изменяется.
- Если найден пустой владеющий указатель — создаём `Node`.
- На обратном пути обновляем высоты и выполняем `rebalance`.
- `size_` увеличивается только при успешной вставке.
- Возвращаем `true` при успешной вставке.
- Реализованы перегрузки `insert(T&&)` и `insert_impl` с перемещением значения при создании нового узла.

### `bool erase(const T& key)`

- Приватный рекурсивный `erase_impl(std::unique_ptr<Node>&, const T&)`.
- Если элемент не найден — `false`.
- Ноль детей: удаляем узел.
- Один ребёнок: переносим владение ребёнком на место удаляемого узла.
- Два ребёнка: используем inorder-successor — минимальный узел правого поддерева.
- Предпочтительно физически переносить узел successor через `unique_ptr`, не копируя `T`.
- Вспомогательный `detach_min()` извлекает минимальный узел и восстанавливает баланс изменённого поддерева.
- После удаления обновляем высоты и балансируем предков.
- `size_` уменьшается ровно один раз при успешном удалении.

### `std::size_t size() const noexcept`

Возвращает поле `size_`. Сложность \(O(1)\).

### `bool empty() const noexcept`

Возвращает `size_ == 0`. Сложность \(O(1)\).

### `void clear() noexcept`

```cpp
void clear() noexcept {
    root_.reset();
    size_ = 0;
}
```

Удаляет всё дерево через цепочку деструкторов `unique_ptr`. Для корректного AVL глубина уничтожения \(O(\log n)\), время \(O(n)\).

## 4. Балансировка

[Пошаговые схемы вращений и передачи владения](avl_rotations.md).

Приватный метод:

```cpp
void rebalance(std::unique_ptr<Node>& link);
```

- `height = 1 + max(height(left), height(right))`.
- `balance_factor = height(left) - height(right)`.
- Допустимые значения: `-1`, `0`, `1`.
- LL/RR — одинарные вращения.
- LR/RL — двойные вращения.
- Вращения изменяют владение через `std::move`, не копируя значения узлов.
- Балансировка встроена в `insert_impl` и `erase_impl`, а не вызывается отдельным обходом после операции.

## 5. Важные ограничения

- Не вызывать публичный `find()` из `insert()` и `erase()`: это создаёт лишний проход и не сохраняет путь предков для балансировки.
- Не выдавать изменяемые ссылки на значения `T` наружу, чтобы не нарушить BST-инвариант.
- Результат `find()` становится недействительным после удаления соответствующего узла, `clear()` или уничтожения контейнера.
- Компаратор должен задавать строгий слабый порядок.
- При написании кода обеспечить безопасность исключений и корректный учёт `size_`.
- `std::unique_ptr` отвечает за владение, ссылки — за доступ, `std::move` — за передачу владения.

**Цель:** чистая, обобщённая реализация AVL с гарантированной сложностью \(O(\log n)\) для поиска, вставки и удаления, пригодная в качестве основы для `Set<T, Compare>`.

## 6. Копирование и перемещение

- Копирующий конструктор копирует компаратор и создаёт независимое дерево. Статический `clone` рекурсивно копирует узлы, сохраняя форму и высоты. Если копирование прерывается, уже созданные узлы освобождаются через `unique_ptr`.
- Дополнительный конструктор `AVLTree(const AVLTree& other, Compare comp)` клонирует те же узлы и сохраняет размер, но использует переданный экземпляр компаратора. Он должен задавать тот же порядок, что и компаратор источника. Это предусловие вызывающего кода, автоматически не проверяется. Такой конструктор позволяет объединению Set копировать большее правое дерево, сохраняя компаратор левого операнда. Если создание компаратора или копирование узлов завершается исключением, частичная копия освобождается, источник сохраняет состояние.
- Копирующее присваивание сначала создаёт полную временную копию. Если копирование компаратора, элемента или выделение памяти завершается исключением, оба исходных дерева сохраняют своё состояние. После успешного копирования временное дерево обменивается состоянием с получателем.
- Конструктор перемещения сначала копирует компаратор. Если его копирование выбрасывает исключение, источник сохраняет своё состояние. После успешного копирования конструктор передаёт корень получателю и обнуляет размер источника. Сам конструктор объявлен `noexcept`, когда копирующий конструктор `Compare` гарантирует отсутствие исключений.
- Перемещающее присваивание обменивает корни, размеры и компараторы, затем очищает источник. Получатель приобретает исходные узлы. Пустой источник можно использовать снова, с прежним компаратором получателя.
- Оба оператора присваивания требуют `swap` без исключений для `Compare`. Самоприсваивание сохраняет состояние дерева.

Копирование требует O(n) времени и памяти для новых узлов. Передача узлов при перемещении занимает O(1). При перемещающем присваивании также уничтожаются прежние узлы получателя, что занимает O(m) для m узлов. Стоимость операций компаратора учитывается отдельно.

## 10. Извлечение поддерева

`get_subtree(const T& key) const` возвращает независимое дерево с корнем по эквивалентному ключу. При отсутствии корня выбрасывается `std::out_of_range`, в том числе для пустого источника.

Приватный find_impl возвращает `const node_link&`, ссылающийся на существующую связь дерева. При отсутствии ключа это ссылка на пустую связь. Возвращаемая ссылка относится к полю дерева, которое остаётся живым после возврата из рекурсии. Публичный find преобразует найденную связь в прежний результат с константной ссылкой на значение.

get_subtree копирует компаратор источника и передаёт найденную связь существующему clone. Сохраняются форма и высоты, узлы результата имеют самостоятельное владение. Количество узлов поддерева определяется отдельным обходом копии, поскольку узлы хранят высоту, а размер учитывается только для целого контейнера.

Поиск занимает O(log(n + 1)), клонирование и подсчёт r узлов — O(r). Итоговое время O(log(n + 1) + r), память под результат O(r), дополнительная глубина рекурсии O(log(n + 1)). Исключения сравнения, копирования и выделения памяти освобождают частичную копию и сохраняют источник.
