AVLTree<T, Compare> — обобщённое дерево поиска с уникальными ключами и AVL-балансировкой. Подключается через tree/avl_tree.hpp. Библиотечная цель nds_lab1_avl_tree передаёт потребителю путь к заголовкам и требование C++20.

## Инварианты и владение

Compare задаёт строгий слабый порядок. Значения a и b эквивалентны, если !comp(a, b) и !comp(b, a). Дубликаты по этому отношению сохраняют ранее вставленное полное значение.

Для каждого узла все значения левого поддерева предшествуют его значению, а правого — следуют за ним. Ограничения действуют относительно всех предков.

Высота пустого поддерева равна 0, листа — 1. Сохранённая высота узла равна 1 + max(height(left), height(right)). Разность высот детей принадлежит множеству −1, 0, 1. Размер дерева равен фактическому числу узлов.

Корень принадлежит дереву, каждый ребёнок — своему родителю через unique_ptr. Узлы Node<T> описаны отдельно. Сырые указатели для работы со структурой не используются.

| Тип доступа | Назначение |
| --- | --- |
| const Node<T>& | чтение существующего узла |
| Node<T>& | изменение полей существующего узла |
| const node_link& | доступ к существующей связи с проверкой пустоты |
| node_link& | изменение связи и владельца поддерева |

Изменение владельца выполняется через std::move. Для невладеющих ссылок внутри очереди обхода применяется reference_wrapper, подробно разобранный в документе об обходах.

## Базовые операции

| Метод | Контракт |
| --- | --- |
| insert(const T&), insert(T&&) | вернуть true только при добавлении нового ключа |
| find(const T&) const | вернуть optional<reference_wrapper<const T>> или nullopt |
| contains(const T&) const | проверить наличие эквивалентного ключа |
| erase(const T&) | вернуть true только при удалении существующего ключа |
| size(), empty() | получить размер и признак пустоты |
| clear() | удалить все узлы, допускается вызов на пустом дереве |
| key_comp() const | получить константную ссылку на экземпляр Compare |
| get_subtree(const T&) const | получить независимую копию поддерева или std::out_of_range |

### Поиск

Приватный find_impl возвращает const node_link& на существующую связь дерева. При отсутствии ключа это ссылка на пустую связь. Возвращаемая ссылка принадлежит структуре дерева и сохраняется после завершения рекурсивных вызовов.

Публичный find преобразует найденную связь в константную ссылку на значение. Владение и узлы остаются внутри дерева. Общий поиск используется также при извлечении поддерева.

### Вставка

insert_impl спускается к месту вставки за один проход. Новый узел создаётся после обнаружения пустой связи. На обратном пути обновляются высоты и восстанавливается баланс. Размер увеличивается один раз после успешной вставки.

Перегрузка с const T& копирует значение при создании узла. Перегрузка с T&& сравнивает исходное значение и передаёт ссылку дальше через std::move. Сам std::move разрешает перемещение, а фактическое перемещение выполняется только при создании узла.

При дубликате объект, переданный через T&&, сохраняет своё значение. Конструктор Node(T) принимает значение по значению и затем перемещает его в поле, поэтому возможны несколько перемещений.

Ошибка сравнения, выделения памяти или создания значения сохраняет прежнюю структуру дерева. Если ошибка возникла во время перемещения T, переданный объект может оказаться изменённым. В map этим объектом является временный результат преобразования.

### Удаление

Узел без детей удаляется, а узел с одним ребёнком заменяется этим ребёнком. При двух детях detach_min извлекает минимальный узел правого поддерева и восстанавливает баланс изменённой ветви. Извлечённый узел переносится на место удаляемого вместе с его связями.

Значение преемника не присваивается значению удаляемого узла. Оставшиеся узлы сохраняют свои адреса. Предки балансируются при возврате из рекурсии, размер уменьшается один раз.

### Срок действия ссылок

Ссылка на значение сохраняется при вращениях и удалении других узлов. Она становится недействительной после удаления своего узла, clear, уничтожения владельца или замены прежнего дерева присваиванием. При перемещении дерева ссылка продолжает относиться к тому же узлу у нового владельца.

## Копирование и перемещение

clone рекурсивно создаёт независимые узлы с исходной формой и высотами. Частичная копия освобождается через unique_ptr при исключении.

| Операция | Поведение |
| --- | --- |
| Копирующий конструктор | копирует компаратор, узлы и размер |
| Конструктор копии с выбранным Compare | клонирует узлы, используя переданный компаратор с тем же порядком |
| Копирующее присваивание | сначала создаёт временную копию, затем обменивает состояния |
| Конструктор перемещения | копирует компаратор до передачи корня и обнуления размера источника |
| Перемещающее присваивание | обменивает состояния и очищает источник |
| Самоприсваивание | сохраняет состояние |

Конструктор с выбранным Compare требует одинакового порядка с источником. Это предусловие вызывающего кода. Оно позволяет Set копировать большее правое дерево с компаратором левого операнда.

Если копирование элемента, компаратора или выделение памяти завершается исключением, источник сохраняется. При копирующем присваивании получатель также сохраняет прежнее состояние. Оба оператора присваивания требуют noexcept swap для Compare, чтобы корень и соответствующее правило сравнения менялись согласованно.

Конструктор перемещения имеет условный noexcept по копированию Compare. Если копирование компаратора выбрасывает исключение, источник сохраняется. После успешного перемещения источник пуст и пригоден к дальнейшей работе. После перемещающего присваивания он использует прежний компаратор получателя.

## Извлечение поддерева

get_subtree находит выбранную связь через find_impl. При отсутствии ключа, включая пустое дерево, выбрасывается std::out_of_range.

Затем создаётся результат с копией компаратора и клонируется найденный узел вместе со всеми потомками. Форма и высоты сохраняются. Отдельный inorder-обход считает размер копии, поскольку в узлах учитывается высота, а размер хранится только для целого дерева.

```cpp
auto subtree = tree.get_subtree(20);
```

Изменение результата не затрагивает источник. Извлечение по листу даёт один узел, по корню всего дерева — независимую копию дерева. Ошибки поиска, копирования или выделения памяти сохраняют источник и освобождают частичный результат.

В консольном меню дерева команда 23 показывает значения, размер и сериализацию копии. Подробности приведены в [руководстве UI](../console_ui.md#режим-дерева).

## Сложность и проверки

Пусть n — число узлов дерева, r — размер извлекаемого поддерева.

| Операция | Время |
| --- | --- |
| find, contains, insert, erase | O(log(n + 1)) |
| size, empty, key_comp | O(1) |
| clear, копирование | O(n) |
| Передача узлов конструктором перемещения | O(1), отдельно учитывается копирование Compare |
| Перемещающее присваивание | O(m) для уничтожения m прежних узлов получателя |
| get_subtree | O(log(n + 1) + r) |

Для get_subtree память результата равна O(r), дополнительный стек ограничен высотой исходного дерева. Стоимость функций сравнения и операций над T учитывается отдельно.

Тесты проверяют базовые операции, четыре случая вращений, несколько балансируемых предков при удалении, инварианты, копирование и перемещение с исключениями, выбранный компаратор, извлечение ветви, листа и всего дерева. Проверки обходов и функциональных операций перечислены в соответствующих документах.
